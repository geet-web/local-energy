LOCAL ENERGY — Assets Folder
==============================

Logo File
---------
Place your logo file here as:  logo.png

The website references it at:  assets/logo.png

Requirements:
- File name  : logo.png  (exact, case-sensitive)
- Format     : PNG with transparent background (recommended)
- Size       : Any — displayed at 44px height, aspect ratio preserved
- Background : Transparent works best over the dark navbar

How to update the logo
----------------------
Simply replace this file with a new version named logo.png.
No code changes are needed — it updates instantly on refresh.

Optional formats
----------------
If you need a different filename or format (e.g. logo.svg),
update the src="assets/logo.png" attribute in index.html 
(appears in navbar line ~26 and footer line ~801).
